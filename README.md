A token launch radar that ranks 198 pre-token protocols by implied value — each protocol's TVL times a peer-derived category multiple from the snapshot's own live-token comparables, adjusted for growth and age — with a sortable dashboard, per-protocol farm plans, and a methodology the judge can audit in the dashboard itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
